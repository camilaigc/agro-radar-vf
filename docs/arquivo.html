Buscar

A busca desconsidera acentuação e diferenças entre maiúsculas e minúsculas. Quando vários termos são informados, apenas os itens que contenham todos eles são retornados; para localizar uma expressão exata, utilize aspas, como em "boa safra". A data considerada é a de publicação da matéria e, quando esta não está disponível, a data em que o item foi coletado.
